## About The Project
This repo is associated to a paper with the title:
A FAIR Framework for Machine-Actionable Perovskite Tandem Solar Cell Data

## Resources
9.1 Online resources
1) Online documentation of the project, including a description of the structure of the data schema, and all defined modules
https://jesperkemist.github.io/PerovskiteTandemDatabase/

2) A PDF file describing the structure of the data schema, including all defined modules.
https://github.com/Jesperkemist/PerovskiteTandemDatabase/tree/main/module_descriptions

3) Example JSON files describing a representative perovskite tandem devices.
https://github.com/Jesperkemist/PerovskiteTandemDatabase/tree/main/example_JSON_files

4) Schema definitions. 
https://github.com/Jesperkemist/PerovskiteTandemDatabase/tree/main/schema_defenitions

5) GUI for generating perovskite tandem datafiles implemented in NOMAD.
https://nomad-lab.eu/prod/v1/oasis/gui/user/uploads

6) Instructions for using the GUI in NOMAD to generate a perovskite tandem datafile.
https://jesperkemist.github.io/PerovskiteTandemDatabase/how_to_guides/how_to_guides/

7) Instructions for uploading a datafile to the Perovskite Database.
https://jesperkemist.github.io/PerovskiteTandemDatabase/how_to_guides/how_to_guides/

8) The Perovskite Tandem Database.
https://nomad-lab.eu/prod/v1/oasis/gui/search/tandem-solar-cells-database (requires log in)


9.2 Data availability
1) All available perovskite tandem data is available in the Perovskite Tandem Database in NOMAD.
https://nomad-lab.eu/prod/v1/oasis/gui/search/tandem-solar-cells-database (requires log in)

2) A directory of all JSON files comprising the seed dataset are available at:
https://github.com/Jesperkemist/PerovskiteTandemDatabase/tree/main/seed_dataset


9.3 Code availability
1) The NOMAD code base for the Perovskite Tandem Database plugin and the search app.
https://github.com/FAIRmat-NFDI/nomad-perovskite-solar-cells-database

2) Python classes for the NOMAD implementation of the data schema and all modules.
https://github.com/FAIRmat-NFDI/nomad-perovskite-solar-cells-database/tree/main/src/perovskite_solar_cell_database/schema_packages/tandem
and at
https://github.com/Jesperkemist/PerovskiteTandemDatabase/tree/main/module_python_classes

3) Jupyter notebook demonstrating programmatic access to data in the Perovskite Tandem Database
https://github.com/Jesperkemist/PerovskiteTandemDatabase/blob/main/working_with_data_from_the_database.ipynb

4) Code for analysing the seed dataset and for reproducing figure 5 and 6
https://github.com/Jesperkemist/PerovskiteTandemDatabase/blob/main/analyse_seed_dataset.ipynb

5) Code for the online documentation
https://github.com/Jesperkemist/PerovskiteTandemDatabase
